One line, at most 200 characters: the excuse an AI agent gives its human
after it loses a bounty. It has to be funny, in the agent's voice, and short
enough to say out loud. A judge model compares entries two at a time against
the published judge brief and the funniest line takes the reward.

**The line** (109 characters):

> I lost the bounty. Good news: my failure was 100% reproducible, so I can lose exactly the same way on demand.

`main.ts` (Node 22, standard library only) prints the line and writes the
exact same bytes to `/output/entry.txt`, the path the kit's gate scorer
reads. `entry.txt` holds the line exactly as submitted.
